# 🔬 Data Description

The dataset is **synthetic**, generated by `python data_generator.py` (seed 42).

| Column | Description |
|--------|-------------|
| **Date** | Daily, 2023-01-01 to 2024-12-30 (730 days) |
| **Product** | Floral Dress, Leather Jacket, Denim Jeans, Chunky Sneaker |
| **Sales** | Daily units sold (target variable) |

2,920 rows in total. The full generation rules (seasonal peaks, step trend, noise) are in [`data/README.md`](../data/README.md).
